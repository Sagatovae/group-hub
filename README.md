# ИДБ-26-09 · Group Hub

Учебное пространство группы: объявления, предметы, разделы и блоки с текстом, файлами и ссылками. React + TypeScript + Vite, Supabase и PWA.

Все посетители могут создавать, редактировать и удалять материалы без регистрации. Предметы и материалы изначально пустые. Название и преподавателя можно изменить у созданного предмета. Общий порядок предметов меняется стрелками вверх/вниз. Объявления можно закреплять и подписывать: «Староста», «Групп.орг», «Проф.орг». Даты в форме создания блока нет.

## Локальный запуск

Node.js 22.12+, рекомендуется 24 LTS. На macOS откройте `start.command` двойным щелчком либо выполните:

```bash
npm install
npm run dev
```

Без `.env` материалы и файлы сохраняются только в IndexedDB текущего браузера. При первом запуске обновлённой версии старые демонстрационные предметы и материалы очищаются один раз; новые данные сохраняются после перезагрузки.

```bash
npm test
npm run build
npm run preview
```

## Общая база Supabase

Обновление уже существующей базы до редактирования предметов, порядка, авторства и картинок: `supabase/migrations/20261019_subject_order_and_authors.sql`. Миграция сохраняет существующие материалы и начальный порядок предметов.


1. Создайте бесплатный проект в [Supabase](https://supabase.com/dashboard).
2. Для нового проекта выполните `supabase/schema.sql` в SQL Editor один раз. Если первоначальная схема с ролями уже установлена, используйте вместо неё `supabase/migrations/20261019_shared_editing.sql`.
3. Скопируйте `.env.example` в `.env` и укажите публичные параметры проекта:

```dotenv
VITE_SUPABASE_URL=https://your-project.supabase.co
VITE_SUPABASE_PUBLISHABLE_KEY=your-public-publishable-key
VITE_BASE_PATH=/
```

4. Перезапустите Vite. Общая база не импортирует локальные материалы автоматически.

Нужны только publishable key или legacy anon key. `service_role` и secret key нельзя использовать в клиенте. Все `VITE_*` параметры входят в публичную сборку.

Схема сохраняет RLS и разрешает чтение и запись ролям `anon` и `authenticated`. Любой посетитель может добавлять, менять и удалять материалы и файлы. Отдельного входа и ролей старосты нет.

Поддерживаемые файлы: PDF, DOC/DOCX, PPT/PPTX, XLS/XLSX, TXT, ZIP, PNG/JPEG/WebP/GIF/AVIF. Картинки отображаются в блоке и открываются в полном размере по нажатию. Собственный лимит размера приложения и bucket снят. На бесплатном Supabase остаётся глобальный лимит тарифа: до 50 МБ на файл. Файлы в bucket `materials` доступны по публичным URL.

## GitHub Pages

Адрес сайта: https://sagatovae.github.io/group-hub/

1. Settings → Pages → Source → **GitHub Actions**.
2. Settings → Secrets and variables → Actions → **Variables**: добавьте `VITE_SUPABASE_URL` и `VITE_SUPABASE_PUBLISHABLE_KEY`.
3. Actions → **Publish to GitHub Pages** → Run workflow.

Workflow проверяет наличие подключения к общей базе до публикации. `VITE_BASE_PATH` задаётся автоматически по имени репозитория. Hash-навигация поддерживает прямые ссылки на предметы. `Check` проверяет тесты и сборку при push и pull request.

## PWA

Production-сайт можно установить через меню поддерживаемого браузера. Оболочка и последняя копия текстов кешируются; при недоступной общей базе сохранённая копия открывается без редактирования. Облачные вложения автоматически для офлайн-работы не скачиваются. Новая версия приложения предлагает обновление. Push-уведомлений и офлайн-редактирования пока нет.

### Установка приложения

На сайте нажмите «Установить». Chrome и Edge покажут системное окно установки, когда браузер разрешит установку. На iPhone откройте сайт в Safari → «Поделиться» → «На экран Домой» → «Добавить». В Safari на Mac: «Файл» → «Добавить в Dock».

PWA открывается отдельным окном и получает обновления через кнопку «Обновить приложение». Ранее загруженная копия материалов доступна без сети; для редактирования и загрузки файлов нужен интернет.

### Telegram

Серверная интеграция публикует новые объявления в @IDB2609 и синхронизирует изменения текста, авторства, картинок и файлов. Подключение бота, секретов и расписания описано в [supabase/TELEGRAM.md](supabase/TELEGRAM.md). До выполнения настройки отправка выключена.

### Push-уведомления

Подписка включается кнопкой с колокольчиком. О новых блоках и материалах приходят push-уведомления с переходом к предмету; на iPhone требуется приложение на экране «Домой». Настройка сервера: [supabase/PUSH.md](supabase/PUSH.md). Telegram теперь публикует и материалы предметов с хештегами.

### Последние публикации

Страница `#recent` объединяет объявления и материалы всех предметов в порядке публикации, без поднятия старых закреплённых блоков наверх. Доступна в боковом меню и нижней мобильной панели. Поиск учитывает предмет, раздел, текст и имена файлов; ссылка на карточке открывает нужный раздел предмета. Кнопка обновления загружает свежую ленту.

### Дедлайны

Вкладка `#deadlines` объединяет объявления и материалы с датой дедлайна.
Календарь начинается с понедельника; точки отмечают события, а выбор дня
показывает все его блоки вместе с файлами и действиями редактирования.
Можно переключать месяцы, вернуться к сегодняшней дате и перейти к ближайшему сроку.
Даты хранятся как календарные дни (`YYYY-MM-DD`), без времени и смещения часового пояса.

В форме создания и редактирования блока дата необязательна; её можно убрать.
У материалов в разделе «Лекции» (включая названия «Лекция…», «Лекционные…»
и `Lectures`) поле скрыто, при сохранении срок становится `null`.
Такие материалы исключены из календаря и подписей дедлайна, даже если в старых
данных сохранилась дата. Дополнительная миграция не нужна: поле `materials.deadline`
типа `date` уже есть в общей базе.
